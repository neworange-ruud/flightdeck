# Video Tutorials

Short narrated videos of FlightDeck in real use. Most show FlightDeck Desktop on
a Mac, driving a worker called `devbox`, with real Claude Code agents building a
small notes app called Pinboard. Each video takes one task from start to finish, in
one to two minutes. Agent work is sped up (the corner says by how much), and
every video has captions.

## Get started

### Set up a worker on your server

<Video src="/videos/tutorials/worker-setup.mp4" poster="/videos/tutorials/worker-setup.jpg"
  captions="/videos/tutorials/worker-setup.vtt" title="Set up a worker on your server" />

Turn a fresh Linux server into a worker: install FlightDeck with one command,
start the worker with `flightdeck worker enable` so it comes back after every
reboot, switch off the agent backends the box doesn't have, and reboot to see
it start by itself. More in [Quickstart: Worker](/worker) and
[Start on boot](/worker/operations#start-on-boot).

### Connect FlightDeck Desktop to a worker

<Video src="/videos/tutorials/connect-worker.mp4" poster="/videos/tutorials/connect-worker.jpg"
  captions="/videos/tutorials/connect-worker.vtt" title="Connect FlightDeck Desktop to a worker" />

Check the worker over SSH, ask it for a pairing code with `flightdeck worker pair`,
and connect from **Connect to remote…**. Includes the one-time warning for a
link outside Tailscale. More in [Quickstart: Worker](/worker).

### Your first agent on a worker

<Video src="/videos/tutorials/first-agent.mp4" poster="/videos/tutorials/first-agent.jpg"
  captions="/videos/tutorials/first-agent.vtt" title="Your first agent on a worker" />

The whole loop: open a project, start an agent, tell it what to build, run the
app in a terminal, try it in the session's browser, have the agent commit, and
**Finish** to merge into main. More in [Agents](/desktop/agents) and
[Git Workflow](/desktop/git).

### Start a new project

<Video src="/videos/tutorials/new-project.mp4" poster="/videos/tutorials/new-project.jpg"
  captions="/videos/tutorials/new-project.vtt" title="Start a new project" />

**Open a project…** on a worker: the projects it already has, browsing to any
folder, cloning a git URL, or creating a new project, which FlightDeck sets up
as a git repository with a first commit. Then the first agent builds the
first version. More in [Projects](/desktop/projects).

## Work with agents

### Run agents in parallel

<Video src="/videos/tutorials/parallel-agents.mp4" poster="/videos/tutorials/parallel-agents.jpg"
  captions="/videos/tutorials/parallel-agents.vtt" title="Run agents in parallel" />

Three agents on one project at once, each on its own branch and worktree,
switched with **Option-1**, **Option-2** and **Option-3**, then merged one

### Mission control

<Video src="/videos/tutorials/mission-control.mp4" poster="/videos/tutorials/mission-control.jpg"
  captions="/videos/tutorials/mission-control.vtt" title="Mission control" />

Every agent as a live tile, the ones that need you first. Answer an agent's

### When an agent needs you

<Video src="/videos/tutorials/agent-needs-you.mp4" poster="/videos/tutorials/agent-needs-you.jpg"
  captions="/videos/tutorials/agent-needs-you.vtt" title="When an agent needs you" />

An agent stops to ask a question: how the sidebar, the Mission control badge
and the project tab tell you, and how to answer in its terminal. More in

### Review before you merge

<Video src="/videos/tutorials/review-changes.mp4" poster="/videos/tutorials/review-changes.jpg"
  captions="/videos/tutorials/review-changes.vtt" title="Review before you merge" />

Check an agent's work before it reaches main: the change count, `git diff` and
the tests in a terminal in its worktree, a revision request, then **Finish**.

### Keep an agent's branch up to date

<Video src="/videos/tutorials/keep-up-to-date.mp4" poster="/videos/tutorials/keep-up-to-date.jpg"
  captions="/videos/tutorials/keep-up-to-date.vtt" title="Keep an agent's branch up to date" />

A teammate pushed to main while the agent worked: pull main in a worker shell,
spot **target +1** in the agent's header, and **Rebase Worktree** to put the
agent's commits on top. More in [Git Workflow](/desktop/git#rebase-a-worktree).

### Let the agent test its own work

<Video src="/videos/tutorials/agent-browser.mp4" poster="/videos/tutorials/agent-browser.jpg"
  captions="/videos/tutorials/agent-browser.vtt" title="Let the agent test its own work" />

Switch **Agent** on in the session's browser, and the agent can use it: here it
builds a note counter, loads the app, adds a note and checks that the count
goes up, while you watch. It stays off until you switch it on, for each
session, and switches off again when you take the browser over or press
**Stop**. Claude Code and Codex agents get the browser tools.

## The worker

<Video src="/videos/tutorials/shells.mp4" poster="/videos/tutorials/shells.jpg"

### Files and images

<Video src="/videos/tutorials/files-and-images.mp4" poster="/videos/tutorials/files-and-images.jpg"
  captions="/videos/tutorials/files-and-images.vtt" title="Files and images" />

Upload a logo with **Transfer files…**, and paste a mockup straight into the

### FlightDeck Web: your worker in a browser

<Video src="/videos/tutorials/web-client.mp4" poster="/videos/tutorials/web-client.jpg"
  captions="/videos/tutorials/web-client.vtt" title="FlightDeck Web: your worker in a browser" />

Pair a browser with the link `flightdeck worker pair` prints, then use the
worker's projects, agents, terminals and command palette from any browser. A
worker serves one window at a time; **Reconnect** in the Desktop takes it back.
More in [FlightDeck Web](/web).

### Hooks: every new worktree ready to run

<Video src="/videos/tutorials/hooks.mp4" poster="/videos/tutorials/hooks.jpg"
  captions="/videos/tutorials/hooks.vtt" title="Hooks: every new worktree ready to run" />

A new worktree gets your `.env` linked in, but nothing else git doesn't track,
so the app won't start. A `worktree_created` hook in `.flightdeck/hooks.toml`
runs `npm install` in every new worktree, and the next agent's app starts right
away. More in [Hooks](/desktop/hooks).

## In your terminal

### FlightDeck in your terminal

<Video src="/videos/tutorials/terminal-ui.mp4" poster="/videos/tutorials/terminal-ui.jpg"
  captions="/videos/tutorials/terminal-ui.vtt" title="FlightDeck in your terminal" />

## How these videos are made

The videos are recorded without anyone at the controls: scripts in the
repository's `tutorials/` folder drive the real FlightDeck Desktop in a macOS
virtual machine against a real worker and real agents, then cut, caption and
narrate the recording. Each one can be recorded again for a new release.
