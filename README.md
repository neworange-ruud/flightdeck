# FlightDeck releases

Release binaries for [FlightDeck](https://www.flightdeckai.app/): the command-line tool and
terminal UI (`v*` releases) and FlightDeck Desktop (`desktop-v*` releases).
This repository holds no source code.

## Install

- **FlightDeck Desktop:** [download the latest release](https://www.flightdeckai.app/download).
- **Homebrew (macOS, Linux):** `brew install neworange-ruud/tap/flightdeck`
- **macOS, Linux:**
  `curl --proto '=https' --tlsv1.2 -LsSf https://github.com/neworange-ruud/flightdeck/releases/latest/download/flightdeck-installer.sh | sh`
- **Windows (PowerShell):**
  `irm https://github.com/neworange-ruud/flightdeck/releases/latest/download/flightdeck-installer.ps1 | iex`

Documentation: https://www.flightdeckai.app/docs
