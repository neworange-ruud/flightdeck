Yes, the QR encodes the code

A QR that only carries the URL trades a real, frequent cost — typing four digits on a phone keyboard, at the exact moment the user is trying to walk away from their desk — for a hazard we cannot detect and the user can. So we encode it, and give the user the control instead: the code and QR render hidden by default when a screen-recording API is active, and r hides them at any time. 120 seconds, one exchange, revocable from the desktop.

D4 — the desktop owns geometry

Upscaling a bitmap grid would make crisp type — the one thing the browser is genuinely better at — into the one thing it does worst.

The dim tier — lifted, not inherited

Facts move up. Anything a user could act on wrongly now sits at --fd-text-quiet (4.8:1): no-upstream, git: ?, the agent display name, (default) origin tags. Absence of information is still information.

The old dim survives for decoration only — key-hint letters that repeat a label already at full contrast, item counts, the │ separator. If deleting it would lose a fact, it cannot be this colour.

The asleep terminal is lifted to 5.6:1 and stays a deliberate exception to nothing: it is a whole screen of text, so 3.7:1 was the least defensible value in the palette. It now reads as “not listening”, not “barely there”.

1h Positions this design takes
Keyboard — palette-primary

Ctrl-g is the only chord FlightDeck Web claims, because it is the only one no major browser takes. Every other command is reachable by its searchable name, with the old key shown beside it in the palette so desktop muscle memory is taught rather than broken. Bare-key App-mode nav (↑↓ ←→ ? Enter) and the Alt/Shift-modified nav survive untouched.

Leaving terminal focus

Click anywhere outside the viewport, or double-tap Esc within 400ms. A single Esc still passes through to the hosted agent, which is what the agent expects. The status bar states both routes permanently — no discovery required.

Dark only — the argument

The main pane is a VT100 surface rendering ANSI colors the agent chose against a dark ground. A light theme would either invert that output — misrepresenting what the agent actually printed — or leave a near-black rectangle covering 70% of a white screen. FlightDeck Web is dark-only, and honest about why: it is a terminal, not a document.

Sidebar right, and narrow

ui.agent_tab_position = right mirrors the body row; the focus glow, the ✕ column and the selection stripe all flip with it — nothing else moves. Below 900px the sidebar becomes a slide-over invoked from a session chip in the project row, and the git bar folds into the status bar.
