KEEPING EVERY HOTKEY

Same keys, now with a visible home

Every current chord stays exactly as it is. Each one also gets a native surface where it can be seen: a menu-bar item, a palette row, or a keycap on the button. The Terminal/App focus model stays too, so a chord FlightDeck owns never reaches the agent by accident.

What a native window gives back
No host terminal sits in between any more, so Cmd on macOS is free for platform conventions (⌘, settings, ⌘Q, ⌘W). The Ctrl and Alt chords keep working the same on all three OSes.
What to guard in a webview
Ctrl-R (reload), Ctrl-P (print), Ctrl +/−/0 (zoom) and Alt-arrows (back/forward) are browser defaults on WebKitGTK. One capture layer has to swallow them before xterm.js sees them, with a key test for each OS.
